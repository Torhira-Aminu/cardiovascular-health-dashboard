# U.S. Cardiovascular Health Dashboard

An interactive public health analytics dashboard built with **Python, Streamlit, pandas, and Plotly** to explore cardiovascular disease patterns across the United States.

## Project Overview

Cardiovascular disease remains one of the leading causes of mortality in the United States. This project transforms cardiovascular health data into an interactive dashboard that allows users to explore patterns across geography, time, age groups, and demographic populations.

The project demonstrates an end-to-end analytics workflow from data structuring and transformation to interactive visualization and insight communication.

## Key Features

* Interactive analysis of cardiovascular mortality across all 50 U.S. states
* State-level choropleth mapping and regional comparisons
* Heart disease and stroke mortality trends from 2000–2021
* Cardiovascular risk-factor analysis across age groups
* Health-equity comparisons across racial and ethnic populations
* Dynamic filtering and interactive Plotly visualizations
* KPI-style summary metrics for rapid interpretation
